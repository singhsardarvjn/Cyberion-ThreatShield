# Cyberion ThreatShield (dashboard)

## Run (VS Code terminal, inside this folder)
```
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000 in your browser. Stop the server with Ctrl+C.

Tabs: Overview, Alerts, Incident timeline, Threat hunts, ATT&CK coverage, Sigma rules, Playbooks.
Buttons: Run detection, Upload logs (.json), download Report / Alerts CSV / Navigator layer.

Command-line version (no browser): `python main.py`
